BAB I: Bilangan Kompleks

Eksplorasi bentuk baku $a+bi$, bidang Argand, konjugat, modulus, argumen utama, dan kalkulator operasi.

Bentuk Baku Bilangan Kompleks

Bilangan kompleks dinyatakan sebagai $z = a + bi$, dengan $a = \text{Re}(z)$ (Bagian Real) dan $b = \text{Im}(z)$ (Bagian Imajiner), di mana $i^2 = -1$.

$$\text{Konjugat: } \overline{z} = a - bi \quad \Big| \quad \text{Modulus: } |z| = \sqrt{a^2 + b^2}$$
Sifat Penting: $z \cdot \overline{z} = |z|^2 = a^2 + b^2$
Komponen Utama:
  • Sumbu Horizontal: Real (Re)
  • Sumbu Vertikal: Imajiner (Im)
  • Panjang Vektor: Modulus $|z|$
  • Bayangan Sumbu Re: Konjugat $\overline{z}$

Perilaku ujung grafik $P(x) = a_n x^n + \dots + a_0$ hanya ditentukan oleh **Derajat ($n$)** (genap/ganjil) dan **Tanda Koefisien Utama ($a_n$)** (positif/negatif).

Kalkulator Pembagian Metode Horner

Metode Horner mempermudah pencarian **Hasil Bagi $H(x)$** dan **Sisa $S(x)$** dari pembagian $P(x)$ oleh pembagi linear $(x - k)$.

Teorema Sisa

Jika polinomial $P(x)$ dibagi oleh $(x - k)$, maka sisa pembagiannya adalah nilai fungsi pada $x = k$, yaitu:

$$S(x) = P(k)$$

Teorema Faktor

Suatu bentuk linear $(x - k)$ merupakan **faktor** dari polinomial $P(x)$ jika dan hanya jika sisa pembagiannya bernilai nol:

$$P(k) = 0 \iff (x - k) \text{ adalah faktor } P(x)$$
